# 功能定义

## 面前材料

支持本地 PDF / 文本与可选飞书招聘简历导入。明确提供的 JD 可作为岗位依据，不从候选人履历反推招聘岗位。通用观察维度为网感、品味、创作能力、AI 理解、产品理解与执行力，不自动生成统一分数。

## 现场记录

电脑微信与麦克风分别采集、录音、转写；按时间显示双方发言。角色来源为音轨，而非声纹识别。采集前检查系统权限及本次录音同意。

## 文字整理

面试结束后允许手动改字或通过 Codex 生成校对草稿。保留数字、否定、个人责任及不确定性。用户确认后显示整理后的正文。引用 ID 保持稳定，原始文本保留在本地存档。

校对按批保存进度，允许停止与续跑。修改正文后重新生成评估，旧评估作为历史保留。

## 独立复核

先基于本场材料及候选人回答生成独立初评并固定，再读取面试官判断做证据对照。初评引用必须来自本场候选人发言；点击引用定位正文。模型结论不自动写回招聘系统，不自动作出录用操作。

没有面试发言时允许保存判断，并提供补充实际问答入口。手动记录标明来源，不伪装成录音逐字转写。不同面试不自动合并。

## 本地数据与模型

语音使用本机 sherpa-onnx；文字处理使用本机 Codex 连接。应用不提供直接模型 API、密钥或模型 ID 配置。材料发送范围、数据位置及删除方式见 [隐私与数据](PRIVACY.md)。
