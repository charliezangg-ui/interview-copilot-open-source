# 隐私与数据

## 处理位置

| 操作 | 本机数据 | 网络传输 |
| --- | --- | --- |
| 音频检测 | 临时两路电平 | 无 |
| 录音与转写 | 双轨 WAV、转写文本 | 无音频上传 |
| 下载语音模型 | 固定版本模型 | 从模型托管服务下载权重 |
| 本地材料导入 | 简历文本 | 无 |
| 飞书导入 | 简历文本与附件副本 | 通过用户的 lark-cli 读取人才与附件 |
| 文字校对 | 草稿、进度、确认后的正文 | 转写与术语表通过 Codex 发送至其配置的服务 |
| 独立初评 | 初评与引用 | 评估规则、候选人材料、面试发言 |
| 判断对照 | 面试官判断及结果 | 判断与对照所需的本场证据 |

本机 Codex 是连接方式，文本推理服务可能位于云端。应用处理前提示发送范围；单次允许仅用于该次操作。“本次运行允许发送文本”不保存为永久授权。

独立初评和文字整理使用新的临时上下文，关闭共享 Memory、项目指令加载及外部工具。面试官判断不进入独立初评，之后才进入对照。应用没有遥测、广告 SDK 或自动上传面试档案的服务。

服务端处理遵循用户的 Codex 账号、服务和组织配置；本应用不承诺替服务方删除数据或零保留。

## 保存位置

根目录为 `~/Library/Application Support/InterviewCopilot/`，可在设置中点击“打开本地存档目录”。

- `Sessions/<会话ID>.json`：材料、发言、判断、初评、校对草稿、原始转写及历史评估。
- `Sessions/<会话ID>-audio/`：`microphone.wav` 和 `wechat.wav`。
- `Imports/`：飞书附件副本。
- `Models/`：语音模型。
- `AgentWorkspace/`：Codex 专用工作目录。

确认优化正文后，界面不再显示原文对照；原始文本仍保留在存档中。修改正文会让当前评估失效，旧评估作为历史保留。

会话及导入文件限制为当前用户读写，未增加应用级加密。系统备份、磁盘加密与云盘同步遵循用户自己的电脑设置。

## 删除数据

退出应用后，通过 Finder 删除对应会话 JSON 和同 ID 录音文件夹。导入附件及手动备份可能独立存在，需要按需一并删除。

删除整个 InterviewCopilot 数据目录会清除全部面试、附件和模型，之后需重新下载模型。Codex 路径偏好不包含登录凭据。

删除本地文件不等于删除系统备份或已发送的文本。处理录音及候选人资料前取得适当授权；反馈问题使用虚构内容或充分脱敏的片段。
