# 界面验收流程

使用虚构候选人材料和获得双方同意的测试通话。将测试会话与真实记录分开。

| 步骤 | 操作 | 核对结果 |
| --- | --- | --- |
| 1 | 新建面试，导入合成材料 | 材料显示正确，旧会话可恢复 |
| 2 | 下载模型，检测 Codex | 状态更新；可手动选择 Codex 并恢复自动查找 |
| 3 | 检测麦克风和微信声音 | 电平跟随对应输入，检测不保存录音 |
| 4 | 开始测试通话并结束 | 发言进入时间线，结束后可回听双轨录音 |
| 5 | 生成校对草稿、编辑、确认 | 正文显示正确，不再展示原文对照 |
| 6 | 保存判断、提交独立复核 | 初评固定后再展示判断对照 |
| 7 | 点击评语引用 | 时间线滚动到对应发言并高亮 |
| 8 | 修改判断后重新提交 | 对照更新，固定初评保持不变 |
| 9 | 退出、重开、恢复本场 | 材料、正文、判断及处理进度恢复 |
| 10 | 取消处理、断开连接后重试 | 保留已保存内容，显示状态及可执行操作 |
| 11 | 空会话保存判断 | 可保存，并可补充实际问答 |
| 12 | 使用相同签名构建下一版 | 旧存档仍可打开，按系统结果核对授权状态 |

合成问答示例：

```text
HR：你在排班工具中负责什么？
候选人：我负责后端接口和部署，界面由同事完成。
HR：上线后如何验证？
候选人：我检查了创建班次和导出流程，目前没有统计长期使用数据。
```

每次验收记录版本、macOS 版本、机器架构和通过的步骤。预期结果不代表已经执行的结果。
